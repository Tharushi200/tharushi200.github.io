Algorithms · Logistics

RouteWise — Multi-Criteria Delivery Route & Package Logistics Optimization Platform

An enterprise-grade desktop software platform engineered to solve real-world urban logistics and package delivery routing across Sri Lanka. Models transport networks as Weighted Graphs, optimizes paths via Dijkstra's Algorithm with custom Min-Heap Priority Queues, manages inventory using an O(log n) Binary Search Tree (BST), and powers continuous shift patrol loops.

  • Traffic-Aware Routing: Dijkstra's Algorithm with dynamic congestion multipliers (1.0x to 2.2x) & travel times
  • Visual Canvas Map & Simulation: Interactive Sri Lanka logistics hubs with animated vehicle dispatch
  • O(log n) BST Package Inventory: Custom Binary Search Tree with QuickSort urgency prioritization
  • Driver Patrol & Navigation: Doubly Linked List stop stepping and Circular Linked List continuous shift loops
